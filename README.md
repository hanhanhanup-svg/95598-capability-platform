# 95598 岗位能力图谱原型

本原型以岗位能力墙为核心，将业务体系、能力标准、人员记录和数据治理连接为可横向复用、纵向追溯的体系。

## 体验路径

- 体系全景：从岗位查看业务、能力和数据关联；支持矩阵、横向协同、纵向追溯。
- 图谱探索：选择岗位或业务场景，缩放、搜索节点，查看任务—能力—等级—行为—证据链。
- 岗位能力墙：查看岗位人员、成长目标、证据覆盖，点击姓名打开能力画像和证据，导出当前筛选结果。
- 业务架构：浏览3个业务域、8个场景、24项任务及12项能力标准。
- 数据治理：目录、血缘、标准、标签、质量和业务映射六个视图相互关联。
- 成长路径：选择同岗进阶或跨岗目标，按差距加入资源、标记训练和提交模拟复测。

建议先体验林悦的故障研判差距，再查看周宁的证据缺口、顾言的过期证据、沈薇的待复核记录。

## 数据与状态

全部40名人员、6类岗位、145条星级能力要求、42条证据和6项数据资产为合成演示。原始附件未提供这些具体人员及评分阈值。

参考匹配度只使用可采信的当前等级，每项按当前等级/目标等级计算并封顶100%，再取均值；缺证、过期和待复核不当零分，同时展示覆盖率。当前星级、目标星级、复测状态分别保存。训练完成与提交复测不会直接改变当前星级。

成长计划仅保存在页面会话中；扩展草稿保存在当前图谱视图中，不进入正式标准和人员评价。刷新会重置模拟状态。没有真实数据接入、后台存储和正式评价系统。

## 本地运行

需要 Node.js 22.13 或更高版本。

```text
npm ci
npm run dev
```

浏览器访问启动信息中显示的本机地址。生产输出：

```text
npm run build
npm start
```

静态部署目录为 `dist/client`，无需数据库、密钥或后台接口。Sites 注册信息在 `.openai/hosting.json`。Windows 构建入口使用自然退出方式，避免上游 CLI 立即退出时的原生句柄关闭异常；非零退出和构建错误保持原样。

## 文件与扩展

- `app/mock-catalog.json`：统一模拟目录、岗位、任务、能力、人员、证据和资源。
- `app/model.ts`：引用查询、分类型差距和指标计算。
- `app/*-view.tsx`：业务视图；`detail-panel.tsx` 为上下游追溯详情。
- `app/platform.css`、`app/extras.css`：国网绿视觉和响应式样式。

通过稳定编码连接实体，新增岗位需要补齐岗位职责、场景任务以及独立的岗位星级能力要求；新增能力需要等级、行为标准、证据用途和成长资源。所有标准进入正式评价前应经人工确认。
